# Market events: test steps

Allow about 15 minutes. Use a demo class, so no real students are affected.

## 1. Schedule controls (instructor)
1. Open your demo class and go to **Market rules**.
2. Find the new **Market events** panel. It should show Chip shortage in Round 4, New rival launch in Round 5 and Tariff on imported parts in Round 6.
3. Change the Tariff to the Final round and click **Save events**. Reload the page and check that the change stuck. Then set it back to Round 6.
4. Turn an event **Off** and save. Then turn it back on.

## 2. What students see
1. Run the demo class to Round 3, then use **View as student** on any team. The Home page should show **Market news** with "Chip makers warn of a shortage" and the label **Expected next round**.
2. Run the class to Round 4. Home now shows "The chip shortage has arrived." On **Decisions > Products**, an advanced-chip product's quote shows a line called **Market event costs included**.
3. In Round 5, Home shows that **Zenra** has launched, along with the segment and region it's aimed at and its one weakness.
4. In Round 6, Home shows the tariff news, and unit costs on Products go up.
5. Check that none of the news items show any exact numbers.

## 3. Event response card (instructor)
1. Once Round 4 has been scored, open any team from the console and click the new **Event response** tab.
2. Each scored event shows its responses (strong, medium, weak or small), whether the team used each one, the details and the outcome.

## 4. Results
- In Round 4 or 5, a team whose plan needed more advanced chips than its allocation sees a "Chip shortage" note in its results, saying what share of those units could be built.

## Notes
- Events apply to every class from now on, including classes already running and the showcase classes. After merging, click **Rebuild on current rules** on the showcase class so it includes the events.
